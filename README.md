# Legal Compliance Reference Bot

Функциональный Telegram-бот-справочник по теме **«Соблюдение правовых норм в профессиональной деятельности»**.

Бот собран на основе материалов из проекта `Musaev-Magomed-Salakh-1.pdf` и дополнен интернет-источниками по трудовой дисциплине, персональным данным и коммерческой тайне.

## Что умеет бот

- Показывает большие теоретические разделы по ключевым правовым темам.
- Даёт чек-лист самопроверки сотрудника.
- Разбирает типовые правовые кейсы и алгоритмы действий.
- Запускает мини-тест по теме.
- Ищет по встроенной базе знаний по ключевым словам.
- Показывает библиотеку официальных и справочных источников.
- Помогает быстро понять, что делать при инциденте: утечка данных, потеря носителя, публикация кода, отправка базы клиентов.

## Запуск

1. Создай бота через BotFather и получи токен.
2. Скопируй `.env.example` в `.env`.
3. Укажи токен:

```env
BOT_TOKEN=your_bot_token_here
```

4. Установи зависимости:

```bash
pip install -r requirements.txt
```

5. Запусти проект:

```bash
python app.py
```

## Команды

- `/start` — старт и главное меню.
- `/help` — помощь.
- `/search запрос` — быстрый поиск по базе знаний.

## Основа контента

Внутри бота отражены темы:

- понятие правовых норм и источники регулирования;
- обязанности работника и трудовая дисциплина;
- работа с информацией, персональными данными и документами;
- коммерческая тайна и конфиденциальность;
- интеллектуальная собственность и ПО;
- профилактика нарушений, комплаенс и локальные акты;
- правовые риски, чек-лист, кейсы, план внедрения контроля.
