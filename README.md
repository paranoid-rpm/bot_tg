# Legal Compliance Reference Bot

Функциональный Telegram-бот-справочник по теме **«Соблюдение правовых норм в профессиональной деятельности»**.

Проект построен на базе материалов `Musaev-Magomed-Salakh-1.pdf` и усилен дополнительными интернет-источниками по трудовой дисциплине, дисциплинарным взысканиям, персональным данным и коммерческой тайне.

## Что умеет бот

- Показывает расширенную теорию по правовым нормам, трудовым обязанностям, дисциплине, режиму работы с данными, коммерческой тайне, ИС и цифровой безопасности.
- Даёт чек-лист самопроверки сотрудника.
- Показывает матрицу видов ответственности.
- Открывает разделы по ролям: сотрудник, руководитель, HR, ИТ/разработчик, оператор ПДн.
- Разбирает типовые правовые кейсы и алгоритмы действий.
- Содержит глоссарий, блок «мифы и правда», шаблоны документов и быстрых памяток.
- Запускает мини-тест по теме.
- Ищет по встроенной базе знаний по ключевым словам.
- Показывает библиотеку официальных и справочных источников.

## Запуск

1. Создай бота через BotFather и получи токен.
2. Скопируй `.env.example` в `.env`.
3. Укажи токен:

```env
BOT_TOKEN=your_bot_token_here
```

4. Установи зависимости:

```bash
pip install -r requirements.txt
```

5. Запусти проект:

```bash
python app.py
```

## Команды

- `/start` — старт и главное меню.
- `/help` — помощь.
- `/search запрос` — быстрый поиск по базе знаний.

## Блоки контента

Внутри бота отражены темы:

- правовые нормы и источники регулирования;
- права и обязанности работника;
- трудовая дисциплина и дисциплинарные взыскания;
- обязанности работодателя;
- персональные данные и обязанности оператора;
- коммерческая тайна и конфиденциальность;
- работа с документами и цифровой перепиской;
- программное обеспечение и интеллектуальная собственность;
- удалённая работа и цифровая гигиена;
- профилактика нарушений, комплаенс и обучение;
- типовые правовые риски, чек-лист, кейсы, шаблоны и алгоритмы реагирования.
